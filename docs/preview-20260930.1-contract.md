# preview-20260930.1 外部契约清单 v1

本清单描述固定预览的实际行为与证据边界，不新增功能或承诺。源码：`450681d71c2fefef0a92e57098643701dabcf4f5`；CI实际checkout：`191d9947d181aab14667562513eae54109a7ea54`，同tree `d0abc20c68ce627015ba2934b38d0a600b812844`。扩展默认SQL **0.1.0**，附可选0.1.1；没有0.1.2。PG18为主，交付包装器仅接受PG18。安全/故障完整资格未完成；只用于本机合成数据、独立实例的初步接入。

**试用前先看三点：** .1包装器AMQP完整编码上限为65,536字节，SQL默认仍1MiB；合法SQL入队超过worker上限后会在AMQP领取时进入dead。TTL/expiry/priority/group只透传，不执行过期删除、优先级或分组调度。正常Close后在途消息须等原租约过期，预览AMQP租约只有2秒。

这些未实现的字段语义目前没有逐消息的告警或特性协商提示：普通发布可能被Accepted，表示已持久接收，不表示字段所暗示的broker功能得到执行。客户端必须按本页白名单设计；若依赖相应语义，应在应用接入检查中拒绝使用，不能以metadata往返测试代替功能验收。

## 三、SQL外部签名与权限

下列是 **SQL0.1.0实际PUBLIC EXECUTE的完整集合**。PUBLIC EXECUTE不绕过队列ACL，也不赋予底表/序列权限。`message_binary`参数未命名；其它参数实际名称带`p_`前缀。应用采用命名参数时必须使用实际名字。

| 完整函数声明形状 | 返回值与行为 |
|---|---|
| `message_binary(bytea)` | bytea；durable binary data section，content-type=application/octet-stream；STRICT：NULL输入返回NULL |
| `enqueue_binary(p_queue text,p_body bytea,p_idempotency_key text DEFAULT NULL)` | bigint；包装应用body后入队；需要produce ACL |
| `enqueue(p_queue text,p_body bytea,p_idempotency_key text DEFAULT NULL)` | bigint；原样存bytea，不校验AMQP；需要produce ACL |
| `read(p_queue text,p_owner uuid,p_visibility_seconds integer DEFAULT 30)` | TABLE(id bigint,generation bigint,body bytea)，零/一行；body为存储编码字节，不自动剥离envelope；需要consume ACL |
| `ack(p_queue text,p_id bigint,p_generation bigint,p_owner uuid)` | boolean；当前未过期凭据才删除消息/释放逻辑容量 |
| `release(p_queue text,p_id bigint,p_generation bigint,p_owner uuid)` | boolean；当前凭据重新可见；耗尽预算则dead |
| `reject(p_queue text,p_id bigint,p_generation bigint,p_owner uuid)` | boolean；当前凭据转dead并保留正文/容量 |

来源：S:226–234,269–277,323–394。确切GRANT类型是 `message_binary(bytea)`、`enqueue_binary(text,bytea,text)`、`enqueue(text,bytea,text)`、`read(text,uuid,integer)`、`ack(text,bigint,bigint,uuid)`、`release(text,bigint,bigint,uuid)`、`reject(text,bigint,bigint,uuid)`。

worker四个函数不向PUBLIC开放：`publish(text,bytea,text)`、`claim(text,text,uuid,integer)`、`settle(text,bigint,bigint,uuid,text,text)`、`authorize(text,text,text)`。只授予受信worker角色；不要让业务用户直接调用显式身份桥接接口。PG17/18 worker可NOLOGIN，PG16配置规则见quickstart:54。

管理员函数：`create_queue(text,bigint,bigint,integer,integer)`返回void，默认10000消息/67108864字节/1048576单条/5次；`grant_queue(text,text,boolean,boolean)`返回void，produce/consume默认true；`revoke_queue(text,text)`返回void；`purge_dead(text,integer DEFAULT 100)`返回bigint，limit为1..10000；`retry_dead(text,bigint)`返回boolean。没有公共peek、延期租约、schedule、修改message、delete_queue或全队列purge接口。来源：S:76–115,339–375,390–394。

0.1.1唯一新增公共读取对象为 `queue_stats` 视图：PUBLIC SELECT，但仅显示session_user具有produce或consume ACL的队列；管理员未授ACL时也不自动显示所有行。包含保留总计，不提供ready/inflight/dead分组。来源：`sql/echoo_pgmq--0.1.0--0.1.1.sql:4–17`。0.1.0调用该视图不可用。
