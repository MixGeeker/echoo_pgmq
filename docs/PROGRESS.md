## 设计边界

- 普通 WAL 持久表；发布成功只能在事务提交后返回；至少一次投递，不宣称端到端 exactly-once
- 首版限定队列拓扑和 AMQP 1.0 子集，不宣称兼容 AMQP 0-9-1 或完整 RabbitMQ 功能
- 首版正在验证双向 TLS 客户端证书身份映射与队列 ACL，默认不提供匿名远程访问；实际客户端配置负担将写入安装说明
- 本仓库不复制 Kafgres 的受限制代码；参考架构与算法独立实现；项目许可证未擅自选定

## 验收不能混为一谈

1. 本地 Linux 运行和 GitHub CI 只证明列明环境里的测试结果
2. GitHub x64 Windows runner 是 Windows Server，不等于门店 Win11（4核/8GB/SSD）验收
3. 强杀进程不是物理断电；真正的 Win11 硬件、SSD 持久性与受控断电验证尚未进行
4. 真实 ERP 联调按计划在独立产品完成后与维护者一起进行；合成数据库负载不是 ERP
5. 当前没有实测吞吐承诺。候选目标“业务峰值2倍、ERP p95增幅不超过10%”需真实业务数据验证

## 发布闸门

草稿 PR、CI 绿灯、候选包均不等于正式发布。需列明安全审查、测试原始数据、已知限制与未运行项目；没有授权前不合并、不生产部署。
